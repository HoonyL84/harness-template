# AGENTS.md에서 참조하는 세부 코딩 규칙 문서

---

## 적용 범위

- `공통 코딩 규칙`, `안전 가드레일`, `행동 원칙`은 모든 프로젝트에 적용한다.
- Spring Boot, JPA, Redis, Kafka 규칙은 `docs/project/PLANS.md`에서 해당 기술을 채택한 경우에만 적용한다.
- 프로젝트 기술 스택과 충돌하면 `PLANS.md`를 우선하며, 불명확한 경우 구현 전에 확인한다.

## 1. 공통 코딩 규칙

- 모든 public 메서드에 Javadoc/JSDoc 작성 (한국어 허용)
- 매직 넘버 금지 — 상수 또는 Enum으로 정의
- 반환값과 오류 계약은 해당 언어와 프로젝트 관례에 맞게 명시한다.
- 로그에 항상 식별자 포함 (campaignId, userId 등)
- 임시 디버그 출력과 시크릿 로그는 남기지 않는다. CLI의 의도된 출력은 유지한다.

## 7. 안전 가드레일

- **DB 쓰기 전 사용자 명시 승인** — 자동 실행 금지
- **프로덕션 배포 명령 자동 실행 금지**
- **파일 삭제 전 사용자 명시 승인**
- `kubectl apply`, `terraform apply` → diff 출력 후 승인 대기
- `.env`, `application-prod.yml` 읽기만 허용, 수정 금지

## 공통 검증

- 실제 프로젝트의 검증 명령과 수용 기준을 따른다.
- 실패 경로와 경계 조건을 테스트하고 비밀값을 기록하지 않는다.
- 기술별 구현/테스트 규칙은 선택형 tech-stack.md를 참조한다.
