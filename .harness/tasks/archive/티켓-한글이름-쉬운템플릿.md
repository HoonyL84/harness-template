## 내용 (무슨 일인가)
- 로컬 티켓 이름에 한글을 허용하고, `create-ticket` 본문을 누구나 바로 이해할 수 있는 `내용 / 원인 / 할 일 / 완료 기준` 구조로 바꾼다.
- 다중 프로젝트 티켓(`request` / `execution` / `history`)에도 사람이 읽는 `title` 필드를 추가한다.

## 원인 / 배경 (왜 하는가)
- 기존에는 티켓 ID와 파일명 검사(`^[a-z0-9-]+$`)가 영문 소문자·숫자·하이픈만 허용해 `harness-pr-merge-execution-archive` 같은 어려운 영어 슬러그만 쓸 수 있었다.
- 티켓 본문도 개발자 위주 영문 섹션(`Goal / Scope / Acceptance Criteria`)이라 한눈에 무슨 일인지·왜 하는지 파악하기 어려웠다.

## 할 일 (무엇을 바꾸는가)
- `tools/harness-cli/task-format.js` 공통 헬퍼를 추가해 한글 티켓명 검증 및 한/영 섹션 파싱을 통합한다.
- `index.js`, `single-repo-task-command.js`, `operations-report.js`, `work-history.js`, `agent-context.js`, `task-blocker.js`가 공통 헬퍼를 사용하도록 전환하고 기존 영문 티켓과의 하위호환을 유지한다.
- `request-plan.js`, `planning-contract.js`, `project-execution.js`에 선택형 `ticket.title` 필드를 지원하고 단위 테스트를 추가한다.
